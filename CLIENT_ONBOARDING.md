# Onboarding клиента Channels-ассистента (пошагово, без удалённого доступа)

Эта инструкция — **для клиента** (Андрей пересылает ей ссылку на этот файл или печатает в чат). Все шаги она делает **сама на своём компьютере**, без AnyDesk/SSH/TeamViewer от подрядчика. Это принципиально: OAuth-ссылка Claude логина блокируется при открытии через удалённый доступ (см. кейс ниже), а 2FA-коды на её аккаунтах всё равно приходят ей на телефон.

**Важно:** не пытайся делегировать эти шаги подрядчику — половина из них требует её аккаунты, её карту и её 2FA. Подрядчик может объяснять, диктовать по видеосвязи, принимать ключи безопасным способом, но **не сидеть в твоём Chrome через AnyDesk**.

## Известный кейс (объяснение, почему без AnyDesk)

При тестировании с прошлым клиентом: Клод заблокировался, когда подрядчик через AnyDesk пытался перейти по OAuth-ссылке. Причина — Anthropic привязывает OAuth-токен к устройству/IP, AnyDesk = ремоут-сессия, геолокация/IP не её, anti-fraud блокирует сессию навсегда. Клиенту пришлось начинать заново.

**Вывод:** OAuth-логины (Claude, иногда Meta) — только сама, в своём браузере, на своём устройстве. Buffer и Telegram-бот — можно через screen share с подрядчиком (там нет device-binding).

## Что понадобится заранее

- Её компьютер (Mac/Windows)
- Её телефон (для 2FA)
- Её карта (для OpenAI, Runway, HeyGen — не для Groq)
- Отдельный email (опционально, для сервисов лучше не личный)
- 30-40 минут на видеозвонок с подрядчиком + 1-2 дня на подготовку в своём темпе

## Этап 1: Подготовка (1-2 дня, делает без подрядчика)

### Шаг 1. Claude Pro/Max подписка

Если уже есть подписка — пропустить. Если нет:
- Зайти на [claude.ai](https://claude.ai)
- Зарегистрироваться / залогиниться
- Оформить **Pro** ($20/мес) или **Max** ($100+/мес) подписку — это обязательно, без подписки OAuth-логин не пройдёт
- Подписку оплачивает она сама (это **её личный Claude**, а не платформа подрядчика)

### Шаг 2. Telegram-бот

- Открыть [@BotFather](https://t.me/BotFather) в Telegram
- `/newbot`
- Придумать имя бота (например «Ашет — личный бренд»)
- Придумать username (например `ashet_olga_bot`, должен заканчиваться на `bot`)
- Скопировать токен вида `123456789:AAFxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` — **это и есть бот**, его никто не должен видеть
- Токен отправить подрядчику безопасным способом (см. шаг 9)

### Шаг 3. Runway (для оживления фото в видео)

- Зайти на [runwayml.com](https://runwayml.com) → Sign Up
- **Account → Billing → Add Payment Method** → привязать карту, пополнить на минимум $5
- **Account → API → Create New Key**
- Назвать ключ `neurostaff-channels-<твоё-имя>` для идентификации
- Скопировать ключ (вида `key_xxxxxxxxxxxxxxxxxxxxxxxx`) — **показывается только один раз**, не потеряй
- Отправить подрядчику

### Шаг 4. OpenAI (для генерации картинок)

- Зайти на [platform.openai.com](https://platform.openai.com)
- Sign Up, подтвердить email, привязать карту (даже если не будешь пользоваться ChatGPT — нужна для API)
- **Settings → Billing → Add funds** (минимум $5, лучше $10-20 на старте)
- **API keys → Create new secret key**
- Назвать `neurostaff-channels-<имя>`
- Скопировать (вида `sk-xxxxxxxxxxxxxxxxxxxxxxxx`) — показывается один раз
- Отправить подрядчику

### Шаг 5. Groq (для распознавания голосовых, бесплатно)

- Зайти на [console.groq.com](https://console.groq.com)
- Sign Up через Google или email
- **API Keys → Create API Key**
- Скопировать (вида `gsk_xxxxxxxxxxxxxxxxxxxxxxxx`)
- Отправить подрядчику

**Groq бесплатный** — карта не нужна, лимит generous (хватает для одного клиента с головой).

### Шаг 6. HeyGen (опционально, только если согласна на видео-аватар)

- Зайти на [app.heygen.com](https://app.heygen.com)
- Sign Up, привязать карту
- **Settings → API → Generate New API Key** → скопировать
- Дополнительно: **Avatar Library → Create → Digital Twin** — загрузить своё фото (или видео), подождать создания аватара, скопировать `avatar_id`
- Дополнительно: **Voice Library → Clone Voice** — записать образец голоса, скопировать `voice_id`
- Все три ключа (API key + avatar_id + voice_id) отправить подрядчику

**Этот шаг опциональный** — если не готова клонировать голос и создавать цифровой аватар, пропустить. Просто не будет функции говорящего видео с её внешностью.

### Шаг 7. Instagram → Business аккаунт

**Только если планируется публикация в Instagram** (иначе пропустить):

- В Instagram: **Settings → Account → Switch to Professional Account → Business**
- Заполнить категорию, контактные данные
- **Settings → Accounts Center → Connected experiences** — привязать Facebook-страницу
  - Если Facebook-страницы нет — создать на facebook.com/pages/create
- Подтвердить права админа

Без Business-аккаунта Buffer не сможет публиковать посты через Instagram API.

### Шаг 8. Buffer аккаунт (для публикации в Instagram)

- Зайти на [buffer.com](https://buffer.com) → Sign Up
- Free-тарифа хватит (1 канал = 1 Instagram-аккаунт)
- В интерфейсе Buffer подключить Instagram через OAuth
- Взять **Access Token**: [publish.buffer.com/settings/api](https://publish.buffer.com/settings/api) → скопировать
- Взять **Channel ID**: GraphQL-запрос (подрядчи поможет с точной командой, нужны organization_id и channels query)
- Оба значения отправить подрядчику

### Шаг 9. Передать ключи подрядчику БЕЗОПАСНО

**Не присылать ключи в обычный Telegram-чат** — история, скриншоты, форварды, всё это утечки. Безопасные варианты:

- **1Password Share** (если используешь 1Password) — генерирует ссылку, которую посмотреть можно один раз
- **Bitwarden Send** (бесплатно) — то же самое
- **Onetimesecret.com** — без регистрации, ссылка сгорает после первого просмотра
- **Через голосовое сообщение или скриншот + подрядчик вручную вбивает** — допустимо, если подрядчик сразу кладёт в Railway-переменные и забывает

Подрядчик скажет, как именно ему удобнее.

## Этап 2: OAuth-логин Claude + Telegram-пейринг (30-40 мин видеозвонок)

**Это самый чувствительный этап — здесь была блокировка через AnyDesk.** Делать только в своём браузере на своём компьютере.

### Шаг 10. Открыть Railway-консоль

- Подрядчик пришлёт ссылку на Railway-проект (вида `https://railway.com/project/<uuid>`)
- Открыть в Chrome / Safari на своём Mac
- Settings сервиса → вкладка **Console** (это реальный pty в браузере)

### Шаг 11. Запустить Claude логин

В веб-консоли Railway выполнить:

```
env HOME=/home/node su -p node -c 'claude --dangerously-skip-permissions'
```

Claude выведет **OAuth-ссылку** вида `https://claude.ai/oauth/...`. Эту ссылку:

- **Открыть в этом же Chrome, в этой же вкладке** (не новой — привязка к устройству/IP)
- **НЕ через AnyDesk, не через ремоут-сессию**
- Пройти 2FA на своём телефоне (код придёт в SMS / push)
- Принять экран **Bypass Permissions mode** (пункт 2 «Yes, I accept»)
- Дождаться, пока Claude запустится в режиме `--channels`

### Шаг 12. Установить Telegram-плагин

В той же веб-консоли, в Claude:

```
/plugin install telegram@claude-plugins-official
/reload-plugins
```

### Шаг 13. Пейринг Telegram-аккаунта

- Открыть Telegram на своём телефоне
- Найти бота (того, что создали в шаге 2)
- Написать ему любое сообщение, например «привет»
- Бот пришлёт **код пейринга** (вида `ABC123XYZ`)
- В веб-консоли Claude выполнить:
  ```
  /telegram:access pair ABC123XYZ
  /telegram:access policy allowlist
  /exit
  ```

После этого контейнер сам поднимется по `ENTRYPOINT` при следующем деплое — ничего руками больше не нужно.

### Шаг 14. Проверка

- Написать боту в Telegram «привет, как дела?»
- Бот должен ответить (это Claude уже работает)
- Можно сразу прислать голосовое — проверить, что распознавание работает (Groq)
- Если что-то не отвечает — написать подрядчику

## Если что-то пошло не так

- **OAuth-ссылка не открывается / выдаёт ошибку** — скинуть подрядчику точный текст ошибки, не пытаться чинить самой
- **Claude после логина молчит** — подрядчик проверит через дирижёр, что контейнер живой
- **Бот не отвечает в Telegram** — проверить, что пейринг прошёл (`/telegram:access list` в консоли)
- **Runway/OpenAI выдаёт ошибку про деньги** — проверить баланс в личном кабинете, пополнить

## Что НЕ должна делать клиентка

- **Не присылать ключи в обычный Telegram-чат** — даже в личку подрядчику. История Telegram = постоянная запись.
- **Не открывать OAuth-ссылку через AnyDesk / SSH / TeamViewer** — заблокируется навсегда.
- **Не передавать аккаунты подрядчику** — Claude, OpenAI, Runway, Buffer остаются на ней, подрядчик только получает ключи через безопасный канал.
- **Не создавать Telegram-бота на чужом аккаунте** — бот = доказательство владения Telegram-аккаунтом создателя.
- **Не регистрировать API ключи на аккаунте подрядчика** — pay-as-you-go биллинг должен быть её, не чужой.
